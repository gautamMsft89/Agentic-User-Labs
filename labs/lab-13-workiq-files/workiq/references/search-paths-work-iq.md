# search_paths

Discover supported native paths when current target/operation evidence is
insufficient. Use the actual descriptor: some catalogs expose `filter`, others
`query`. Do not invent backend/provider/HTTP-method parameters or alternate
tool names. A reference is not a schema. Reuse useful same-transcript discovery.

Files/OneDrive, Teams channels/messages and SharePoint are discovery concepts,
not guessed exact paths. A result establishes advertised addressing, not access,
unique file identity or successful execution. Avoid broad catalog enumeration
when an exact native target and compatible contract are already known.
If discovery returns an error, preserve it; do not invent schemas or delegate
to an opaque question-answering tool. Load `troubleshooting` if useful.
